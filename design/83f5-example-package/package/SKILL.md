# Open an unfamiliar system

Use this checklist before planning the first acquisition on an unfamiliar rig.

1. Read the current system state. Record the active camera, objective, channels,
   exposure and current stage position; ask about anything you cannot identify.
2. Check the pixel size and its calibration before converting image distances
   into stage moves. If it is unknown, keep measurements in pixels.
3. Read the stage limits and motion safety configuration before requesting a
   move. Ask the user which sample region is safe; do not infer it from limits.
4. Prefer one saved frame at the current position to a long acquisition.
   Inspect its focus, illumination and saturation with the user.
5. Agree on the intended region, exposure and stopping point before a longer
   run. Save the session's acquisition script when the plan is ready to reuse.
